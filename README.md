# Taniti Travel

A tourism website prototype for WGU D479.

- **Initial Prototype:** `initial.html`
- **Revised Prototype:** `revised.html`

## Changes in the revised version

1. Travel Information has a Getting Around shortcut above the currency cards.
2. The desktop and mobile menus include a Saved Activities link.
3. Lodging details use the label Prepare a booking checklist.

These revisions were based on simulated feedback examples, not completed participant sessions. Actual guerrilla testing remains to be completed and documented separately.

## Hosting

These are static files. Publish the default branch root through GitHub Pages.
The root page links to both versions. No build or installation is needed.

Booking interactions create a demonstration checklist, not a reservation.
